# Corporate Template v2.3 — layouts

Use the exact name in the outline's `layout` field. All slides output at **13.33 × 7.5 in**.

| Layout | Use for |
|---|---|
| Cover Green | Default deck cover (brand marketing default) |
| Cover Blue / Cover Indigo | Cover variants; hue order green → blue → indigo signals scale |
| Cover with Multiple Speakers | Event / panel covers |
| Cover with Subtitle | Cover with a supporting line |
| Title Only | Custom visuals drawn with shapes |
| Title with Subtitle | Headline + subhead, open canvas |
| Title and Content | Standard bullets |
| Title and Content Sans Subhead | Bullets without subhead |
| Title with Two / Three / Four Columns and Headers | Parallel ideas, comparisons |
| Five Columns with Cards | Five "because" argument cards |
| Four Groups with Cards / Six Groups with Cards | Grouped capability cards |
| Title with Two Graphics / Title with One Graphic / Title Subtitle with One Graphic | Screenshots, diagrams, renders |
| Table Center | Data tables |
| Quote | Customer quote + attribution |
| Statement Green / Blue / Indigo | One big statement |
| Divider Green / Blue / Indigo | Section breaks |
| Weighted Right Graphic / Weighted Left Graphic | Split text + image |
| Demo Full Screen, Demo Intro Desktop/Tablet/Mobile, Demo Desktop, Demo Tablet Horizontal/Vertical, Demo Mobile | Product demo frames, videos |
| Safe Harbor | Required legal slide for forward-looking content |
| Thank You Blue / Thank You with Photography | Closer |
| Logo Slide | Logo lockup |
| Blank | Full-bleed custom |
| ~~Do not use~~ | Never |

Run `python scripts/list_layouts.py` to see each layout's placeholders (index, type, position) before filling.
