Capability column head for platform diagrams — the four pillars Sense, Decide, Act, Secure, each with an "ANY x" capsule.

```jsx
<CapabilityTile hue="sense" title="Sense" label="Data" />
<CapabilityTile hue="decide" title="Decide" label="AI Model" />
<CapabilityTile hue="act" title="Act" label="Workflow" />
<CapabilityTile hue="secure" title="Secure" label="System, Identity, Asset" />
```

- Hue map: sense = Indigo, decide = Purple, act = Blue, secure = Wasabi Green.
- Children render below the capsule (feature lists).
