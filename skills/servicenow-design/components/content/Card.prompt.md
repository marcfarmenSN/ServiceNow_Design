Rounded brand panel that holds grouped content on dark gradient backgrounds (cards layouts, pillars, stats).

```jsx
<Card variant="template" style={{ width: 324, height: 692 }}>…</Card>
<Card variant="glass" scale={0.5}>…</Card>
```

- `template`: Infinite Blue @5.3% fill + 1px white line (Corporate Template "Five Columns / Four Groups with Cards").
- `glass`: translucent light gradient + soft white edge (pitch-deck panels). Default.
- `light`: white card for light documents.
- `scale`: 1 = slide canvas (radius 23px); 0.5 for web.
